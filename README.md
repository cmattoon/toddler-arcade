Toddler Arcade
==============

This is a vibe-coded arcade "platform" for baby and toddler games that uses arcade buttons and a joystick.
The main design goal of the games is that each button press corresponds to something meaningful (not just more lights and noise).
After the first few games, I thought I'd attempt a stricter version of this where each game addresses one or more developmental goals.
This is still a work in progress.

Hardware
--------

The initial "Type 1" gamepad was built using the following:
  - [EG STARTS DIY Kit](https://www.amazon.com/dp/B0762CZBZH?ref=ppx_yo2ov_dt_b_fed_asin_title)
  - [EG STARTS 6x 30mm White Buttons](https://www.amazon.com/dp/B07GBTLSQ5?ref=ppx_yo2ov_dt_b_fed_asin_title&th=1)
  
I used a sharpie (then, printed sticker) to add shapes to the white buttons:
  - Square
  - Circle
  - Triangle
  - Diamond
  - Star
  - Heart

I originally purchased these with the intention of making a row of 6 buttons, but ended up with two rows of three because that fit better on my first case.

The gamepad "types" are intended to deal with different physical layouts, but this feature isn't really developed yet.
